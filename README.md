# 光域 · 内外双层自适应采光系统 —— 使用说明

> 版本：方案 B · 概念设计验证 · 2026-09
> 适用对象：产品概念评审、人因分析复核、参数化建模与二次开发

---

## 1. 项目简介

「光域」是一套**内外双层自适应采光系统**的参数化情境交互模型，用于靠窗办公场景下的直射光、屏幕反光与人工控制研究。

- **外层智能玻璃**（电致变色，x ≈ −25 mm）：负责整体光线与热量调节，按上 / 中 / 下三分区独立变色。
- **内层微型百叶**（x ≈ 95 mm）：负责快速、局部阻挡眼睛和屏幕方向的直射光（防眩光）。
- **两层之间**为 120 mm 空气间隙。

模型将窗体、百叶、办公工位和简化坐姿人体统一在同一个参数体系（单位 mm）下，同时输出三维交互展示、人因分析指标、OBJ 网格、JSON 参数与 SVG 尺寸图。

> **定位声明**：这是几何情境模型，不是光学仿真。未计算透射、散射、亮度、DGP、照度或热舒适，不能据此判定视觉舒适、节能效果或产品合规性达标。

## 4. 交互模型操作指南

打开 `光域交互模型.html` 后，页面分为三个区域：顶部操作栏（情境模式 + 视图 / 导出按钮）、左侧设计参数面板、中央 3D 视口，右侧为分析结果与 IoT 感知面板。

### 4.1 情境模式

顶部四个模式按钮一键切换系统状态，玻璃颜色与百叶角度会平滑渐变到目标值：

| 模式 | 玻璃状态 | 百叶角度 | 台灯 | 场景说明 |
|---|---|---|---|---|
| 正常办公 | 透光（α≈0.10） | 30° | 关 | 自然采光充足 |
| 西晒防眩光 | 中下区变深（0.68 / 0.52） | 75° | 关 | 阻断屏幕方向直射光 |
| 投影会议 | 整体变暗（0.82） | 85° | 开 | 台灯补光 |
| 傍晚节能 | 恢复透明（0.06） | 20° | 开 | 台灯补光 |

- 模式切换后进入**自动控制**状态；拖动「百叶倾角」滑块则进入**人工接管**，状态标签变橙色并倒计时，30 秒后自动恢复，也可点「自动恢复」立即还原。

### 4.2 设计参数（左侧面板）

点击左上角「☰ 设计参数」展开面板，所有参数实时生效：

| 参数 | 含义 | 范围 | 基准值 |
|---|---|---|---|
| 窗宽 | 窗体水平宽度 mm | 1400–2200 | 1800 |
| 窗高 | 上下框中心线间距 mm | 1500–1900 | 1600 |
| 窗台高度 | 下框中心标高 mm | 650–850 | 800 |
| 眼位距窗 | 坐姿眼点距窗面水平距离 mm | 650–1300 | 900 |
| 坐姿眼高 | 眼点标高 mm | 1050–1350 | 1200 |
| 桌面高度 | 桌面标高 mm | 680–800 | 740 |
| 下 / 中分界 | 中区下边界标高 mm | 1000–1150 | 1100 |
| 中 / 上分界 | 上区下边界标高 mm | 1450–1650 | 1550 |
| 百叶倾角（手动） | 叶片绕轴倾角 ° | 0–90 | 30 |
| 太阳高度角 | 太阳相对地平线仰角 α ° | 5–65 | 25 |
| 太阳偏离窗法线 | 太阳水平方向偏角 β ° | −60–60 | 0 |

面板底部提供快捷预设：**低眼高（1100）/ 基准（1200）/ 高眼高（1300）**，以及「重置全部」。

### 4.3 视角与视图

- **拖动**：旋转模型；**滚轮**：缩放；**双击**：复位视角。
- 顶部视图按钮：`轴测`、`窗正视`、`工位侧视`，一键切换观察角度。

### 4.4 爆炸图

点击「爆炸图」按钮，模型沿 X 轴分层展开（外层玻璃 → 百叶 → 家具），并显示 7 项部件编号标注与「双层分工说明」，用于讲解系统结构；再次点击恢复装配。

### 4.5 导出功能

| 按钮 | 导出内容 | 用途 |
|---|---|---|
| 导出 OBJ | 当前参数的 `光域模型.obj` | 分组网格，可导入其他 3D 软件继续编辑 |
| 导出参数 | 当前参数的 `光域参数.json` | 复现当前设计状态 |
| 导出尺寸图 | 当前参数的 `光域尺寸图.svg` | 带标注的概念尺寸图（非加工图） |

### 4.6 IoT 感知面板与状态解读

右侧面板实时显示 7 项指标：

- **室外 / 室内照度**（lx）：室内照度由模式基值按玻璃透明度估算，非实测；
- **工位有人**：占用感知（模式定义值）；
- **屏幕眩光**：几何判定（非直射模式 + 百叶 < 40° + 太阳高度 > 18° + 玻璃较透时提示 ⚠）；
- **玻璃透光**：按玻璃平均不透明度换算的百分比；
- **百叶角度 / 台灯补光**：当前状态。

中央状态栏给出**直射路径判定**三种结论：

1. 「眼位回溯光线未进入窗净开口」→ 当前几何下无该路径直射；
2. 「与百叶或框体相交 → 直射路径被遮挡」→ 防眩光有效；
3. 「未被遮挡 → 存在直射路径」→ 需调整百叶或工位。

右下角注释为技术边界说明：直射判定采用平行太阳光线与理想薄百叶相交，未计算玻璃透射、散射、亮度、DGP、照度或热舒适；人体采用分段简化几何。

## 5. 人因分析报告要点

打开 `02-人因分析/人因分析报告.html`，包含 8 个章节，核心结论：

1. **分区遮阳应按光线路径选择**，不能只按眼高所在区域：基准眼高 1200 mm 位于中区，但太阳高度角 25° 时窗面交点约 1620 mm 已进入上区——只启动中下区会遗漏该路径。
2. **三种眼高情景**（1100 / 1200 / 1300 mm）的视距为 618 / 631 / 658 mm，均落在 OSHA 推荐 50–100 cm 区间；但低眼高与基准情景的显示器上缘仍偏高，建议显示器提供 ≥150 mm 独立竖向调整行程。
3. **控制器可达距离** 478–575 mm（肩点到控制器直线距离），建议移至鼠标附近常用操作区并允许左右手换位。
4. **交互设计建议**：人工选择后保持、显式恢复自动、立即反馈执行状态、设置滞回防频繁动作、按窗区绑定工位、不承诺未验证的「隐私」单向可视。
5. **优先改进**：按眼位—太阳路径选分区、显示器独立高度调节、控制器可移动，随后做光学模型与真实工位试验（建议先开展 6–8 人探索性可用性试验）。

## 6. 模型引擎 model.js 二次开发

`model.js` 是独立建模引擎，无 DOM 依赖，同时兼容浏览器与 Node.js（CommonJS），导出 8 个 API：

| 导出 | 说明 |
|---|---|
| `defaults` | 基准参数对象（与 `光域基准参数.json` 一致） |
| `sceneModes` | 四种情境模式定义（玻璃颜色、百叶角、照度、台灯） |
| `sceneState` | 场景动画当前状态（模式、玻璃渐变、百叶角、爆炸系数） |
| `build(p, st)` | 构建全部部件网格（返回分组立方体对象数组） |
| `sunRays(p, st)` | 阳光射线几何计算（窗口点、百叶点、屏幕点、遮挡判定） |
| `iotState(p, st)` | IoT 感知状态（照度、眩光、透光率、模式） |
| `analysis(p, st)` | 人因分析（视距、视角、可达距离、直射判定、分区） |
| `objText(p, st)` | 导出当前场景的 OBJ 文本 |

### Node.js 示例

```bash
npm init -y   # 或直接复制 model.js 到项目目录
```

```js
const { defaults, sceneModes, build, analysis, objText } = require('./model.js');

// 1. 使用基准参数做一次人因分析
const a = analysis(defaults);
console.log('视距', Math.round(a.view), 'mm');
console.log('向下视角', a.down.toFixed(1) + '°');
console.log('眼高所在区', a.zone);
console.log('存在直射路径', a.direct ? '是' : '否');

// 2. 切换到「西晒防眩光」模式并导出 OBJ
const st = { ...require('./model.js').sceneState, mode: 'antiGlare' };
const fs = require('fs');
fs.writeFileSync('antiGlare.obj', objText(defaults, st));

// 3. 修改参数做敏感性分析
const p = { ...defaults, eye: 1100 };
console.log('低眼高视距', Math.round(analysis(p).view), 'mm');
```

### 参数传递约定

- `p`：设计参数对象，必须包含 `defaults` 中的全部键（缺省可整体用 `defaults`）；
- `st`（可选）：场景状态对象，缺省使用模块内全局 `sceneState`；
- 单位一律为 mm（角度除外），坐标：x 向室内、y 沿窗、z 向上。

## 8. 已知限制与免责声明

1. **非光学仿真**：未计算玻璃透射 / 散射 / 反射、亮度分布、DGP、照度或热舒适；「室内照度」「眩光」为几何估算值，不输出虚构 lux 数值。
2. **直射判定为理想几何**：仅覆盖单个理想眼点；头部移动、不同太阳方向、区域边界空隙及邻座位置均可能改变结论，不得概括为「30° 可消除眩光」。
3. **人体为分段简化体块**：未做关节运动学、姿态评分与真实可达包络验证。
4. **OBJ 为分组网格**：可导入继续编辑，但**不是** SolidWorks 等 CAD 的特征树 / 装配 / 加工文件；SVG 尺寸图为概念标注，非加工图。
5. **无自动控制实现**：交互页面只计算静态几何，不连接传感器、不执行自动控制，也未模拟玻璃响应时间。
6. **未做工程验证**：夹手风险、驱动噪声、清洁可达性、窗户启闭冲突、断电释放能力等均需按所选器件另行确认。
7. **设计假设**：全部尺寸为可修改的概念假设（基于《光域双层窗人因设计方案.docx》），三组眼高为敏感性情景，不代表中国成人百分位。
